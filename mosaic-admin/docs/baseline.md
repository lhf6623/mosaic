## 有意不改（与旧仓的差异清单）

- **不做 1:1 复刻**：只做探针切片，字段 / 交互按"能暴露风险"挑选。
- 路由 hash 形如 `#/pages/...`（G2 起外壳自建路由，hash 是 admin 相对路径，子路径部署不带前缀）。
  这是与 P0 首版的差异：P0 用 o-app + o-router 时 hash 会带 `/mosaic-admin/` 前缀，G2 换外壳后不再带。
- 旧仓的 Vue2 组件 / 构建链一律不复用；只抄与框架无关的纯函数和数据形状。
- 旧仓近期提交（如 15:19 的委托单号搜索属性）**默认不回搬**，等模块切换时统一对账。
