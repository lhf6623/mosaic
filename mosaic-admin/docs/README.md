## 一页速览

- 新工程**不是 1:1 复刻**：只做探针切片；旧仓继续演进，不追平。
- 只有两个关键指标：**每类页面的人日**、**10 标签下的内存与帧率**。其余是守卫指标。
- 最可能翻车的两条：**模板表达力不足导致命令式 DOM 化**（`proto` 里 DOM 操作 ≤25%）、
  **shadow DOM 实例成本**（10 标签 ≤400MB、帧率 ≥50fps）。
- 失败合法：预算上限 2 人 × 10 周；放弃也要留下组件、令牌、性能基线与一份结论清单。
- 发布标准 ≠ "admin 做完了"，而是"契约连续 4 周零 breaking + 仓库外能独立消费"。
