# mc-pagination

> 共用约定（五个正交维度、值读写、事件、插槽 / part 命名）与组件索引见 [`packages/README.md`](../README.md)。
> 源码 `./pagination.html` · **已实现**

分页。给总条数与每页条数，它渲染页码条：上一页 / 下一页翻页，方向键在按钮之间移动焦点，页数多了自动折叠成省略号；翻页发 `change`。打开 `jumper` 多一个跳页输入框，打开 `sizer` 多一个每页条数选择器。

初始值写属性 `default-current`，运行时值读写宿主 property `current`：它不是 `attrs` 键，也不会反射成属性。

```html
<mc-pagination total="85" page-size="10" default-current="3"></mc-pagination>
```

---

## 属性

| 名称              | 值                     | 默认           | 说明                                                                     |
| ----------------- | ---------------------- | -------------- | ------------------------------------------------------------------------ |
| `total`           | `number`               | `0`            | 总条数；不写就是一页（页码条仍在，但前后都不可点）                       |
| `page-size`       | `number`               | `10`           | 每页条数；小于 1 按 1 算                                                 |
| `default-current` | `number`               | `1`            | 初始页码；越界会夹回 `[1, 总页数]`，运行时改它只在没写过 property 时生效 |
| `sibling-count`   | `number`               | `1`            | 当前页两侧各显示几个页码；页数不多时忽略它、全部列出                     |
| `size`            | `'sm' \| 'md' \| 'lg'` | `md`           | 控件高度与字号                                                           |
| `disabled`        | `boolean`              | —              | 整条禁用：所有按钮都点不动，跳页输入框也不可编辑，也不会发 `change`      |
| `jumper`          | `boolean`              | —              | 在页码条右侧显示「跳至 __ 页」输入框：回车或失焦提交，越界夹回           |
| `sizer`           | `boolean`              | —              | 显示「每页 __ 条」选择器（原生 `<select>`）：换条数会发 `change`         |
| `page-sizes`      | `string`               | `10,20,50,100` | 选择器里的候选项，逗号分隔；当前 `page-size` 不在列表里时会补进去        |

## 事件

| 名称     | 类型                                                                       | 说明                                                                                                                                        |
| -------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `change` | `(event: Event & { data: { current: number; pageSize: number } }) => void` | 使用者翻页（点页码 / 上一页 / 下一页 / 跳页输入框）或换每页条数，且 `current` / `pageSize` **真的变了**时触发；写入 property `current` 不发 |

## 插槽

| 名称     | 说明                                                       |
| -------- | ---------------------------------------------------------- |
| `prefix` | 页码条**之前**的附加内容（如「共 85 条」），跟着宿主横排   |
| `suffix` | 页码条**之后**的附加内容（如每页条数选择器），跟着宿主横排 |

## part

| 名称     | 说明                                          |
| -------- | --------------------------------------------- |
| `list`   | 页码条（`<ul>`，布局与间距都在这里）          |
| `item`   | 每个页码按钮（当前页带 `data-current`）       |
| `prev`   | 上一页按钮                                    |
| `next`   | 下一页按钮                                    |
| `jumper` | 跳页输入框那一格（`跳至 __ 页` 的 `<label>`） |
| `input`  | `jumper` 里那颗原生输入框                     |
| `sizer`  | 「每页 __ 条」那一格（`<label>`）             |
| `select` | `sizer` 里那颗原生 `<select>`                 |
