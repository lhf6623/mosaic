# mc-scroll-bar

> 共用约定（五个正交维度、值读写、事件、插槽 / part 命名）与组件索引见 [`packages/README.md`](../README.md)。
> 源码 `./scroll-bar.html` · **已实现**

滚动条：把内容包进来，条子由组件自己画（覆盖式，不占内容宽度），**滚动本身仍是原生的** ——
键盘、触屏惯性、锚点、页内查找全都照旧，只是原生滚动条被藏起来、换成跟着主题走的那一条。
条子平时藏着，**鼠标移入才淡入**（`reveal="hover"`，默认）；键盘焦点进来、正在拖滑块时同样可见
（触屏设备没有「移入」这个动作，退回「溢出即常显」）。要它一直在 —— 截图、大屏演示、内容很小而
条子本身就是主体的界面 —— 写 `reveal="always"`。

和「直接给容器写 `overflow: auto`」的分工：原生滚动条的宽度、圆角、颜色、出现时机在各平台与
各浏览器上都不一样（`scrollbar-width` 与 `::-webkit-scrollbar` 是两套），而且**占位的滚动条在
出现 / 消失时会让内容横向跳一下**。要「滚得跟设计系统一致」，用它。

```html
<mc-scroll-bar style="height: 12rem">
  <p>很长很长……</p>
</mc-scroll-bar>

<!-- 横向：宽表格、代码、时间轴 -->
<mc-scroll-bar axis="x" style="height: 4rem">
  <div style="width: 60rem">…</div>
</mc-scroll-bar>
```

> 高度（或宽度）**由使用者给**：组件只管滚动与画条子，不猜你要多高 ——
> 没给高度时宿主的 `auto` 高度会跟着内容长，永远不溢出，也就永远不滚。

## 属性

| 名称     | 值                    | 默认    | 说明                                                                                                                                |
| -------- | --------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `axis`   | `'y' \| 'x'`          | `y`     | 哪条轴滚动。一次一条 —— 两条轴同时要的场合用普通 `overflow` 容器                                                                    |
| `reveal` | `'hover' \| 'always'` | `hover` | 条子什么时候出现：`hover` = 鼠标移入才淡入（键盘焦点在内部、拖拽中同样可见；触屏没有「移入」，退回常显）；`always` = 只要溢出就常显 |

## 事件

| 名称     | 类型                     | 说明                                                                                                                                    |
| -------- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| `scroll` | `(event: Event) => void` | 内部滚动时从**宿主**上冒泡出来。原生的 `scroll` 不冒泡、viewport 又在 shadow 里，外面够不着，所以这里重发一次（`bubbles` + `composed`） |

## 插槽

| 名称     | 说明       |
| -------- | ---------- |
| （默认） | 滚动的内容 |

## part

| 名称       | 说明                                                                                  |
| ---------- | ------------------------------------------------------------------------------------- |
| `viewport` | 真正滚动的那个元素；改内边距、底色都改它                                              |
| `bar`      | 条子（轨道）：占位 / 宽度；默认透明，鼠标移入宿主（键盘焦点在内部、拖拽中同样）才淡入 |
| `thumb`    | 滑块：颜色、圆角                                                                      |
