## 设计取舍

1. **截断和浮层在同一个组件里**：长文本显示不是「一个省略号 + 原生 title」，用户需要读到 / 选中 /
   复制完整内容。原生 title 不可选中、不可复制，而且样式不可控。
2. **浮层必须可交互**：`pointer-events: auto`、`user-select: text`、鼠标可以从触发区移进面板；
   面板里放「复制」按钮，选中复制和按钮复制两条路都通。tooltip 的「非交互、不抢焦点」结论在
   这里不适用 —— 这里的内容就是正文。
3. **只用原生 popover + CSS 锚点定位**：与 tooltip / popover 同一套浮层结论，不挂 body、不用 z-index；
   没有 popover API 时退回原生 `title`（信息不丢，但不能选中复制）。
4. **只在截断时弹**：默认避免短文本也弹浮层；`always` 可显式打开。触发区始终可聚焦（键盘可达），
   Escape 关闭并把焦点还给触发区。
