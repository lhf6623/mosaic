# mc-scroll-area

> 共用约定（五个正交维度、值读写、事件、插槽 / part 命名）与组件索引见 [`packages/README.md`](../README.md)。
> 源码 `./scroll-area.html` · M3 · **已实现**

滚动容器：把内容包进来，滚动条由组件自己画（覆盖式，不占内容宽度），**滚动本身仍是原生的** ——
键盘、触屏惯性、锚点、页内查找全都照旧，只是原生滚动条被藏起来、换成跟着主题走的那一条。

和「直接给容器写 `overflow: auto`」的分工：原生滚动条的宽度、圆角、颜色、出现时机在各平台与
各浏览器上都不一样（`scrollbar-width` 与 `::-webkit-scrollbar` 是两套），而且**占位的滚动条在
出现 / 消失时会让内容横向跳一下**。要「滚得跟设计系统一致」，用它。

```html
<mc-scroll-area style="height: 12rem">
  <p>很长很长……</p>
</mc-scroll-area>

<!-- 横向：宽表格、代码、时间轴 -->
<mc-scroll-area axis="x" label="横向滚动的内容" style="height: 4rem">
  <div style="width: 60rem">…</div>
</mc-scroll-area>
```

> 高度（或宽度）**由使用者给**：组件只管滚动与画条子，不猜你要多高 ——
> 没给高度时宿主的 `auto` 高度会跟着内容长，永远不溢出，也就永远不滚。

## 属性

| 名称    | 值           | 默认         | 说明                                                                         |
| ------- | ------------ | ------------ | ---------------------------------------------------------------------------- |
| `axis`  | `'y' \| 'x'` | `y`          | 哪条轴滚动。一次一条 —— 两条轴同时要的场合用普通 `overflow` 容器（见下）     |
| `label` | `string`     | `可滚动区域` | 可滚动区域的读屏名（`role="region"` + `aria-label`，**只在真溢出时才挂上**） |

## 事件

| 名称     | 类型                     | 说明                                                                                                                                    |
| -------- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| `scroll` | `(event: Event) => void` | 内部滚动时从**宿主**上冒泡出来。原生的 `scroll` 不冒泡、viewport 又在 shadow 里，外面够不着，所以这里重发一次（`bubbles` + `composed`） |

## 插槽与 part

| 名称              | 说明                                     |
| ----------------- | ---------------------------------------- |
| 插槽 （默认）     | 滚动的内容                               |
| `part="viewport"` | 真正滚动的那个元素；改内边距、底色都改它 |
| `part="bar"`      | 条子（轨道）：占位 / 宽度 / 出现时机     |
| `part="thumb"`    | 滑块：颜色、圆角                         |

> **无障碍**：真的溢出时 viewport 会挂上 `tabindex="0"` + `role="region"` + `aria-label`，
> 键盘能 Tab 进来、用方向键与 PageUp/Down 滚；不溢出时三个属性一起撤掉 ——
> 否则就是一个按了没反应的 tab 停靠点。滑块本身 `aria-hidden="true"`。
>
> **滚到底不锁住**：容器滚到尽头后，滚轮会**继续交给外层**（页面照常往下滚），
> 不会把鼠标困在容器里。要「滚不出去」的内滚区（弹层场景），自己给
> `::part(viewport)` 写 `overscroll-behavior: contain`。
>
> **两条轴同时滚的场合**：用普通的 `overflow: auto` 容器。这个组件一次只画一条轴，
> 两条轴的自定义条子（两个滑块互相影响、角落交叉）不值得为它把接口撑大一倍。
