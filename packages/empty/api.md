# mc-empty

> 共用约定（五个正交维度、值读写、事件、插槽 / part 命名）与组件索引见 [`packages/README.md`](../README.md)。
> 源码 `./empty.html` · **已实现**

空态：没有内容可显示时的一块占位 —— 内置图形 + 一行文案 + 可选的操作区。

```html
<mc-empty></mc-empty>
<mc-empty description="没有匹配的记录"></mc-empty>
<mc-empty description="还没有项目">
  <mc-button slot="footer" color="primary">新建</mc-button>
</mc-empty>
```

图形是内置的（图标集里的 `empty`），不需要也不接受 `name` / `src` —— 空态不挑图，要换颜色的走
`--mc-empty-image-color` 或 `::part(image)`。

---

## 属性

| 名称          | 值                     | 默认       | 说明                                                            |
| ------------- | ---------------------- | ---------- | --------------------------------------------------------------- |
| `description` | `string`               | `暂无数据` | 主文案；默认插槽给了内容就整块让位                              |
| `size`        | `'sm' \| 'md' \| 'lg'` | `md`       | 图形与文案一起三档：1.75em / 2.5em / 3.5em 的图形，字号各差一档 |

## 插槽

| 名称     | 说明                                          |
| -------- | --------------------------------------------- |
| （默认） | 描述区内容；给了就顶掉 `description` 的纯文本 |
| `footer` | 操作区（按钮 / 链接）；不给就整块不占位       |

## part

| 名称          | 说明                                 |
| ------------- | ------------------------------------ |
| `base`        | 整体（内边距与三行之间的间距在这里） |
| `image`       | 内置图形                             |
| `description` | 描述区                               |
| `footer`      | 操作区                               |
