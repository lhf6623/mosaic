评分。一排星，点第几颗就是几分；支持半星、自定义颗数与语义色。原生 range 只管键盘与焦点，指针交互按星星真实几何换算。

## 设计取舍

**原生 range 只做键盘与焦点，指针交互自己接。** 评分的点击语义是「点第几颗星就是几分」，
半星再按每颗星的左右半边分；而原生 range 的点位是按整条宽度等比映射的，星星之间有间距时
「点第 5 颗的中心」会落到 4.5 而不是 5。所以内部 `<input type="range">` 设成
`pointer-events: none`，只负责 Tab / 方向键 / Home / End 与焦点；`pointerdown` /
`pointermove` 由组件按 `part="item"` 那一排的真实几何换算分值，指针捕获后连续拖动照常连发
`input`。

**悬停预览只画、不动值。** 指针扫过星条时按当前位置把星「预填」到目标分，离开或松手就回到
真实值；预览期间不改原生 range 的值、也不发事件 —— 使用者看到的和点下去会得到的是同一个数。

**快速取消是显式开关。** 开了 `clearable` 之后，点击当前分值所在的星（按下后不拖动、松手）
就清回 0；清空同样走 `input` / `change`，载荷 0；键盘 Home 本来就回到 0。默认不开 ——
评分通常是有意给出的，重复点同一颗星不该被当成「再点一次就清空」的默认行为。

**半颗星 = 两层星裁一半。** 每颗星是两层 SVG：底层空星描边、顶层实心星；顶层外面套一个
`overflow: hidden` 的盒子，`data-fill="half"` 时裁到 50%。裁的是「整颗星的一半」，不是把星
缩小，所以半星和整星一样大、描边也对得上。`data-fill` 只有 `empty` / `half` / `full` 三态，
CSS 只认它。

**渲染是模板的事。** 星条由 `<o-fill :value="rows" fill-key="id">` 渲染：一颗星一行，行模型只有
`id` 与 `fill` 两个字段，空 / 半 / 满三态仍落 `data-fill`，CSS 选择器一个没改。脚本不再
`createElement` / `innerHTML` 造可见结构，`paint()` 只更新行模型；留在行为层的只有模板表达
不了的那几件 —— 指针坐标 → 分值的换算（量 `part="item"` 那排的真实几何）、原生 range 的焦点 /
键盘、指针捕获与拖动、悬停预览状态。

**`value` 是 number，走表单控件那套。** `value` 是 observed attribute + 宿主 property
（绑定通道 `:value` / `sync:value` 落在它上面，写完立刻生效），`default-value` 只作非受控初值、
挂载读一次；0 就是未评分。和 slider 一样，写值会按 step 归一（allow-half 时 0.5，否则 1）、
超出 `max` 会夹紧；归一后把 `value` 属性同步成实际值。`mc-form` 收集时按字符串收
（同原生 `FormData`）。

**默认色用 `warning`。** 评分通常是暖色强调；想要品牌色写 `color="primary"`，想完全自定就覆盖
`--mc-rate-fill` / `--mc-rate-empty`。`color` 也收 hex（走共享接线器，只填实心星那一槽）。

**已知边界。** 没有 `readonly`（只读展示用 `disabled`，或干脆不监听事件）；`max` 取正整数，
非整数四舍五入。

## 令牌

| 令牌              | 默认（按 size）                            | 作用                                                 |
| ----------------- | ------------------------------------------ | ---------------------------------------------------- |
| `--mc-rate-star`  | `1.25rem`（sm `1rem` / lg `1.5rem`）       | 单颗星直径；数字 size 按 px 写它                     |
| `--mc-rate-h`     | `--mc-control-h-md`（sm `-sm` / lg `-lg`） | 行高下限；数字 size 放大星标时行高取 `max(它, 星标)` |
| `--mc-rate-gap`   | `var(--mc-space-1)`                        | 星与星之间的间距                                     |
| `--mc-rate-fill`  | 按 `color`（默认 `--mc-color-warning`）    | 实心星颜色；hex 时由接线器改写                       |
| `--mc-rate-empty` | `--mc-color-border-strong`                 | 空星描边颜色                                         |

> 令牌不进**文档页**（页面参考区只渲染 api.md 的白名单四节），将来由主题编辑器展示。
