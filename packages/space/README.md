## 设计取舍

**只做一件事：直接子项之间的间距。** 宿主是一个 flex 容器，间距交给 `gap` —— 不是给子项加
`margin`：`gap` 只出现在相邻项之间（首尾天然不补），换行后行距与列距一致，文本节点也会被
当成一项（flex 的匿名 item），不需要额外包一层。

**间距三档 + 数字（px）。** `gap` 的 `sm` / `md` / `lg` 与 `mc-grid` 用同一条映射
（`--mc-space-2/4/6`）；要 10px 这种值直接写 `gap="10"`（纯数字按 px）。数字由组件写进宿主的
内部变量 `--mc-space-gap`，**不用再覆盖 CSS 变量**；回到三档时变量删掉、交回 CSS 属性选择器
（同 `mc-grid` 的 `cols`）；非法值（包括 `12px` / `0.75rem` 这类带单位的字符串）落回默认 `md`。

**`justify` 管主轴，`align` 管交叉轴。** `justify` 映射 `justify-content`：`start` / `center` /
`end` / `between` / `around` / `evenly`；不写时是 `start`（flex 默认的 flex-start）。
反向属性叫 `reverse-order`，不叫 `reverse`：ofa 元素 API 自带 `reverse()` 方法（同 `wrap`），
同名会把函数写进属性。它只翻主轴方向：横向 `row-reverse`、纵向 `column-reverse`。

**默认是行内 flex。** Space 通常出现在一句话或一行工具条里，`inline-flex` 不会把上下文断成块；
整行场景用 `block`（同 `mc-button` 的 `block` 命名），宿主才变成 `display: flex; width: 100%`。

**交叉轴默认按方向走：横向居中、纵向拉伸。** 横向混排文字 / 图标 / 按钮时居中最稳；纵向列表
（一列输入框、一列按钮）通常希望同宽。显式 `align` 一律盖过这两个默认值，包括 `stretch`
（横向想让一排卡等高时用）。

**换行属性叫 `wrap-items`，不叫 `wrap`。** ofa 的元素 API 自带 `wrap()` 方法，`attrs` 里声明
同名键 `wrap: null` 会在挂载时命中它、把函数源码写进 `wrap` 属性（实测），随后 CSS
`:host([wrap])` 对所有实例都成立。所以布尔换行用 `wrap-items`（数据键 `wrapItems`）。

**JS 只做两件小事。** 挂载后与属性变化时：① 把 ofa 布尔绑定写出的 `wrap-items="false"` /
`reverse-order="false"` / `block="false"` 收成「有 / 没有」（见 [`packages/README.md`](../README.md) §1.4）；
② 把数字 `gap` 写进宿主的 `--mc-space-gap`（三档或非法值时删掉）。没有
MutationObserver、不改使用者的 DOM，子项增删 / 重排由浏览器自己做。

**刻意不做 `split`（分隔符）。** 在子项之间插一条线要么改 light DOM（和 ofa 的模板重渲染打架），
要么用 `::slotted()::before`（规范不允许在 slotted 伪元素后再接伪元素）。需要分隔就在元素之间
自己放一个 `<span>` 当普通 flex 项，`gap` 会自然把它夹在中间。

## 令牌

| 令牌                                             | 默认                             | 作用                                                   |
| ------------------------------------------------ | -------------------------------- | ------------------------------------------------------ |
| `--mc-space-gap`                                 | `--mc-space-4`                   | 数字 `gap` 的落点（内部变量：JS 按属性写，不是覆盖点） |
| `--mc-space-2` / `--mc-space-4` / `--mc-space-6` | `--mc-def-space-2` / `-4` / `-6` | `gap` 的 sm / md / lg 读取的全局间距令牌               |

> ⚠️ 目录名 `space` 让 drift 的组件令牌前缀 `--mc-space-` 与全局间距令牌撞名：这张表里
> `--mc-space-2/4/6` 是组件**消费**的全局令牌，不是可覆盖的组件令牌；`--mc-space-gap` 是
> 数字通道的内部落点（JS 按 `gap` 写，不是覆盖点）。调间距用 `gap` 属性（数字也行），
> 不要单独覆盖令牌。

## 相邻单元

- 与 [`mc-grid`](../grid/) 的分工：grid 是二维（列数 / 跨列 / 最小宽度），space 只有一维
  （一行或一列 + 一个间距档 / 一个数值）；只排一行元素时用 space，要分列 / 换成网格时用 grid。
- 与 [`mc-form`](../form/) 的分工：表单的行距、标签与控件的间距由表单单元自己的令牌管；
  space 不参与表单布局，避免两套间距来源。
